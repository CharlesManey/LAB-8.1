This was a great lab working with Copilot to create a basic flash card App. You can add new flash card decks and within the decks you can add new flash cards. There are 2 themes (light and dark) and 2 modes.
Library mode where you have the power to add, edit, delete, and go straight into shuffle study. Study mode where you can then use your library to study your flash cards with mouse or keyboard.

Reflection

* AI definitely saved time in setting up the project and doing the tedious boilerplate tasks.
* AI did not incorporate a lot of edge cases, and overlooked a lot of possible bugs or things that might hinder user experience
* I did not have to refactor any code other than altering some media queries to get my animations to work.
* Theme Switcher and fixed some incorrect keyboard navigation. Also made keyboard navigation target the card when switching to study mode so the user could interact with the cards right away.
* I always told the AI to operate as an expert software developer and tried to make my prompts as contextual as possible.
